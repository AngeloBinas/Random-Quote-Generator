## Project Overview
Team Quote created a random quote generator as part of the IT 110 web application project. The application requests a quote from the DummyJSON Quotes API and displays it with the author name in a clean and responsive user interface.

## Project Goal
The goal of the project is to provide a simple and polished way for users to generate inspiration with a single click while demonstrating front-end web development using HTML, CSS, and JavaScript.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- DummyJSON Quotes API

## Files Included
- `index.html` — portfolio landing page
- `app.html` — quote generator page
- `styles.css` — shared styling for the site and app
- `script.js` — fetch logic and quote rendering
- `README.md` — project documentation

## How to Run the Project
1. Open the project folder in a browser.
2. Open `index.html` to view the portfolio page.
3. Click the "Try the quote app" button to access the quote generator.
4. Keep an internet connection enabled so the app can request quotes from DummyJSON.

## API Information
- Random quote endpoint: `https://dummyjson.com/quotes/random`
- API documentation: `https://dummyjson.com/docs/quotes`

## Features
- Random quote generation from a public API
- Clean and responsive layout
- Loading status while fetching data
- Friendly fallback message when the API is unavailable
- Accessible status updates for user feedback

## Notes
This project is built as a front-end web app and does not require any backend setup or installation process. It is intended to be opened directly in a browser for demonstration and class submission.
