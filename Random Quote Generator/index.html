We are Team Quote, building a simple, thoughtful way to find a little inspiration with HTML, CSS, JavaScript, and a public API.

The project

Our idea and the tools behind it

The Random Quote Generator requests a new quote from the DummyJSON Quotes API and displays it with its author. Our goal is a clean, responsive experience with clear loading feedback and a friendly message if the request cannot be completed.
